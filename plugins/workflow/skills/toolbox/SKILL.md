# Toolbox

Identify only the capabilities required by the task, then use an available local availability check or the tools' documented version/status commands. Distinguish executable presence from authenticated access and correct project selection. Do not install, log in, inspect secret values, broaden permissions, or change live services without authorization. Report missing tools and exact verification limits.
