# Plan work

Inspect the request and relevant project evidence. Separate requirements, verified facts, assumptions, and choices. Break the work into independently reviewable outcomes with dependencies, ownership, relevant paths, tests, risk, and approval boundaries. Keep the plan in the project's chosen location only when authorized. A plan or proposal is not permission for a live operation. Do not proceed past a decision the user must make.
