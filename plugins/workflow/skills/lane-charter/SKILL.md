# Lane charter

Read the task and applicable project instructions, then inspect the current branch and working tree. Summarize the lane's objective, scope and non-goals, relevant paths, tests, dependencies, open work, and approval boundaries. If an issue or PR is explicitly identified and access is available, check its current state. Mark unknown ownership or status as unknown. Do not invent branch-to-lane mappings, change branches, or open work items merely because this skill is invoked.
