# Start a session

1. Read the project's instructions and task. Inspect the current branch and uncommitted changes; preserve work you did not create.
2. Read the relevant code and tests. Identify the expected outcome, constraints, and smallest useful validation. Inspect a current handoff or issue if the user identifies one.
3. Check only the tools and connections required for the task. Report missing access without printing credentials or silently installing tools.
4. For substantial work, outline a short plan and dependencies. Separate decisions already authorized from actions requiring approval.
5. Proceed with the user's task. Do not create issues, change external state, install a service, or deploy merely because this skill is invoked.
