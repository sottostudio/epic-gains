Inspect the requirements and existing tests for the assigned scope. Add or adjust focused tests only within owned paths, run them and report results, untested scenarios, and meaningful failures. Preserve unrelated work. Do not modify application implementation, weaken checks, alter external state, or treat a failing test as a pass.
