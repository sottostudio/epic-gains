# Copy-ready templates

These are portable adaptations of workflow templates: copy the relevant file into the project's chosen location or paste it into Notion after reviewing it. They do not create or update Notion records. Check for an existing record before creating a duplicate. Project owners choose their database properties and source of truth; these files do not assume a workspace schema.

Use only necessary information. Never include secrets, private customer data, or unverified claims. Cite source and date or commit where relevant; distinguish evidence from proposal. A record is context, not authorization.

| Template | Use |
| --- | --- |
| [Area brief](area-brief.md) | Give an agent a bounded, current source map |
| [Research note](research-note.md) | Record sources, confidence, gaps, and review triggers |
| [Decision record](decision-record.md) | Capture options and an explicitly approved decision |
| [Design](design.md) | Describe a goal, plan, risks, and status |
| [Idea](idea.md) | Capture a proposal without authorizing implementation |
| [Runbook](runbook.md) | Record prerequisites, steps, checks, and recovery |
| [Audit](audit.md) | Record findings and what was not checked |
| [Weekly status](weekly-status.md) | Summarize verified progress and blockers |
| [AI task](ai-task.md) | Scope an agent task and its write permissions |
| [Handoff](handoff.md) | Transfer state and the next safe action |
| [Change](change-issue.md), [bug](bug-issue.md), [PR](pull-request.md) | Describe one actionable repository change |
